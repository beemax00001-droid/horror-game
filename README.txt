راه‌اندازی:
1) محتویات این پوشه را در ریشه Repository گیت‌هاب قرار بده.
2) مطمئن شو index.html در ریشه Repository باشد.
3) Settings > Pages > Deploy from branch را انتخاب کن.
4) Branch اصلی و پوشه /root را انتخاب و Save کن.
